🚀 Product Hunt 新品

    新上榜：Cloudflare 的 AI 模型，主打又快又便宜的数据抽取。独立站和跨境站本来就在 CF 上的，结构化抓取、清洗又多一个原厂选项。

    新上榜：像审 Pull Request 一样审 AI Agent 的 Markdown 规格。团队开始让 Agent 写文档、跑流程时，先把「规格」纳入评审，少踩一次幻觉。

  3. Peras

    新上榜：在 Claude Code / Codex 烧掉你一周算力之前先按暂停。个人和小团队控成本用，比事后看账单舒服。

  4. Gerty

    新上榜：装在 Mac 上的私有 ChatGPT 替代，宣称能自己完成初始化。不想把工厂数据送进公有云的，可以当本地助手试。

  5. Inyon

    新上榜：在手机上回复正在跑的编码 Agent。人不在电脑前也能拍板，适合远程和出差场景。

  6. Polylane for Cloudflare

    新上榜：给 Cloudflare 应用配的 AI 值班工程师。站多、报警多的团队，可以先让它分流再人工接手。

  7. Plango

    新上榜：用 AI 防御 AI——对抗滥用、自动化攻击一类场景。投放账号、店铺接口被刷时，值得看一眼思路。
