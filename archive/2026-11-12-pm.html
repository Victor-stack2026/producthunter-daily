  6. 给 GitHub Actions 加上锁文件

    约 255 分：Hugo van Kemenade 介绍 GitHub Actions 现已支持工作流锁文件。此前常见做法是把动作钉在完整提交哈希上，因为标签可被改写、存在供应链风险；文中演示用官方扩展 gh-actions-lock 来生成和锁定这些文件。
