🚀 Product Hunt 新品

早班之后新面孔（已剔除往期）

  1. MiniMax M3.1 Flash

    新上榜：号称面向 Agent 快 3 倍、便宜约 70% 的 Flash 模型。客服/跟单助手算 Token 账时，可当低延迟备选扫一眼。

  2. ManyAgents

    新上榜：一个 Mac 窗口指挥一队编程 Agent。同时改独立站、脚本与数据管道时，少切窗口。

  3. VibeiDE

    新上榜：并行排队 Agent 任务并逐条审结果。批量出详情页文案/素材验收时，先把「队列+人工过目」搭上。

  4. AVP

    新上榜：面向 AI 编程 Agent 的开源 Git 替代思路。多 Agent 改同一仓库怕互相踩脚时，值得看一眼协作模型。

  5. tabsh

    新上榜：浏览器标签里直接开 IDE 跟 Agent 干活。出差只带浏览器也能改站点/脚本时，可当轻量入口。

  6. AI Bridge

    新上榜：把 Mac 上各家编程 Agent 各归其位。Cursor/Claude/本机助手并用时，少一层「谁在占资源」混乱。

  7. omerta

    新上榜：拦住 .env 密钥漏进 git。独立站、支付与 ERP 插件一多，先把泄密门关上再谈 Agent 自动化。
