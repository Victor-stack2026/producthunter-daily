  2. Java4Shell：OpenJDK 的 Base64 解码存在远程代码执行漏洞

    约 491 分：Calif Research 披露 Java4Shell（CVE-2026-114938），称这是 OpenJDK 为加速 Base64 解码而使用的底层指令中的内存损坏漏洞，CVSS 4.0 评分为 9.2。他们表示在默认配置下，已在 Keycloak、Jira、Confluence、Jenkins 等应用中演示未授权远程代码执行，客户端通过 TLS 连接恶意服务器也可能受影响。Oracle 已在 11 月 17 日发布补丁，OpenJDK 亦发布安全公告。

  3. 怎样为每个模型选择最合适的智能体框架

    约 332 分：Runta 与 Baseten 合作发布 FrontierHarness Eval v1.1，用 22 种框架、5 个模型和 62 项任务做评测。作者认为换模型时也应考虑换框架：性价比最高的组合因模型而异，例如 GLM-5.3 搭配 Codex CLI，DeepSeek V4.1 Flash 搭配 ZCode，Kimi-K3 搭配 Alma；同一框架的成本排名在不同模型之间可以差距很大。

  4. 微软推出 MAI Code 2 与 Code 2 Flash

    约 282 分：微软在 Ignite 发布面向日常企业编程任务的 MAI Code 2 及其更轻量的 Flash 版本。官方称，在多项日常编程评测平均值上，Code 2 达到 GPT-6.1 Sol 约 98% 的表现、成本约为后者的 40%，并达到 Claude Opus 5.5 约 96% 的表现、成本约为 5%。两款模型已进入 GitHub Copilot，Flash 还在 Microsoft Foundry 限量预览。

  5. Claude Code 团队如何看待验证

    约 261 分：Addy Osmani 撰文介绍 Claude Code 团队的验证方法。文中称团队约 90% 的代码由 Claude 编写和审阅；有了可验证闭环，才适合并行运行大量智能体。文章强调端到端测试、性质测试和差分测试，并提醒测试不能太脆弱或太慢，检查应由代码负责人维护，变更不能改写自己的裁判。
