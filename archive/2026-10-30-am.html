晚班之后新面孔优先，再补往期未收录（约一半中文）

  1. [TBPN] Diet｜谷歌财报、黄仁勋遭间谍盯梢、华尔街假交易员崛起

    晚班之后新上线：30 分钟压缩今日 TBPN——谷歌财报、供应链安全与「假交易员」叙事并排。跟投广告/云预算时，对照听大厂业绩和地缘噪声怎么同时进盘面。

  2. [Dwarkesh] 从 LBJ 与罗伯特·摩西学到的权力课

    晚班之后新上线：Dwarkesh 把 Caro 传记备忘录做成视频随笔——伟大工程背后是交易与意志。谈渠道、工厂谈判或品牌落地时，听听「权力」如何被具体操作，而不只是口号。

  3. [No Priors] Serval：把编码 Agent 交到企业 IT 手里，挑战 ServiceNow

    晚班之后新上线：Sarah Guo / Elad Gil 对谈 Serval CEO——让非工程师也能用 Agent 搭流程。工厂上工单/质检自动化时，对照听「谁能改流程」比「模型多强」更关键。

  4. [Odd Lots] 华尔街现在怎么看 AI 交易

    晚班之后新上线：Anthropic S-1 与超大规模云财报同周，市场波动怎么定价「AI 叙事」。看供应链与广告预算时，可当一集情绪温度计。

  5. [How I AI] Grok vs Dot vs Muse vs Claude Duet：个人 Agent 横评

    晚班之后新上线：九项真实任务（Slack、Sentry、Figma、收件箱等）跑四款个人 Agent。选型办公助手时，别只看发布会——听谁真能做完、谁会半路掉链。

  6. [a16z] 为 AI 时代重做学校｜Joe Liemandt、Gagan Biyani

    往期未收录：Alpha School 主张 AI 加速学习后，多出来的时间应练「非卷分数」技能。带团队/招新人时，对照听培训目标要不要跟着模型能力一起改。

  7. [Latent Space] 为什么 Agent 爱用 Supabase

    往期未收录：Supabase 联合创始人谈长生命周期工作负载与 schema。自建客服/跟单 Agent 要落库时，听听后端要为「Agent 写软件」改什么。

  8. [跨国串门儿] #801 当智能免费时，什么仍然有价值

    晚班之后新上线：克隆 Invest Like the Best×Cliff Sosin——智力补不出现实世界信息。做品牌与渠道时，想想哪些「互补资产」才是真正稀缺。

  9. [声动早咖啡] 好莱坞恐怖片大年，为什么这类电影越来越多？

    晚班之后新上线：用类型片潮汐看内容供给与情绪消费。女内品牌做内容投放时，可对照「低成本高情绪」品类为什么容易起量。

  10. [Web Worker] No.104 代码都让 AI 写了，面试到底还在面什么？

    晚班之后新上线：HR 视角谈 AI 时代招聘——内推仍占大头、JD 匹配也不回音。小团队招开发/运营时，先想清楚要验「会用工具」还是「能扛结果」。

  11. [AI炼金术] AI 帮我干完了 20 年的活儿，我却感觉像坐牢

    往期未收录：徐文浩/任鑫谈「AI 写完了，人验收不完」。工厂用 Agent 出方案/改文案时，先定验收清单，否则吞吐上去、决策瓶颈更堵。

  12. [十字路口] AI 无限，人生有限｜对谈 KK、山音

    往期未收录：两位 AI 导演把电影梦落到作品与电影节。品牌视觉/短视频想「用 AI 出片」时，听听品味与选题怎么比工具更稀缺。

  13. [硬地骇客] EP128 从 Palantir 到 OpenAI：FDE 会成 AI 时代新岗位？

    往期未收录：前线部署工程师如何填「模型能力」和「业务价值」的最后一公里。上 ERP/客服 Agent 时，对照听要不要有人驻场把流程焊死。

  14. [半拿铁] 番外16 「情绪价值经济学」：花钱买开心是不是好生意？

    往期未收录：播客节现场聊体验、圈层与自我认同消费。女内品牌定调「舒服/仪式感」时，可对照听情绪溢价怎么定价才站得住。

    新上榜：不离开 ChatGPT 就能搭并发布真实应用。想快速验证独立站小工具/活动页时，可当「对话里出产品」试点。

  3. Flatbread

    新上榜：分享整段 Agent 运行过程，而不只是截图。团队复盘客服/改站 Agent 时，完整轨迹比结果截图好追责。

  4. JIMMY

    新上榜：跑在你 PC 上的本地 AI Agent。图纸、成本表不想上云时，对照听本地执行与工具权限怎么划。

  5. Arco

    新上榜：在 Codex 里直接看 GitHub / Linear issue。小团队用编码 Agent 改站时，工单进上下文能少来回切窗口。

  6. Smart Jelly

    新上榜：把日常 AI 工具和记忆收进一个 Mac App。个人知识库+写作助手想少开十几个标签时，可扫一眼。

  7. Confetti

    新上榜：用自然语言做硬件小玩意。打样/展会小道具想「先说话再出板」时，当创意原型通道看看。
